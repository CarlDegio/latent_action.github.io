公式 · 物理意义 · 数值方向

A = oₜ，B = oₜ₊₁，R = recon。oₜ / oₜ₊₁ 分别表示相邻时刻观测，recon 表示重建结果。S、E、P 分别表示 SSIM、MSE、PSNR，基础公式见下方。

计算口径

成功率

每行、每个 Head 内的分项成功率取等权算术平均。LIBERO / LIBERO-Plus 为 4 项，RoboTwin 为 2 项。DAP 与 LAP 均值是同一实验两种 Head 平均成功率的等权平均。保留原始 0 值，不对不同实验再做聚合；任一 Head 缺失时，二者均值也视为缺失。

s = (s₁ + … + sₖ) / k
s_DAP/LAP = (s_Head1 + s_Head2) / 2

Pearson 与 Spearman

Pearson 衡量线性关系；Spearman 衡量单调关系，先对两列分别排名，相同值使用平均秩，再计算秩的 Pearson 系数。

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[Σ(xᵢ − x̄)² Σ(yᵢ − ȳ)²]
ρ = Pearson(rank(x), rank(y))

线性拟合

x 为代理指标，y 为平均成功率（0–1），使用带截距的普通最小二乘拟合。图中纵轴以百分比显示；拟合公式仍使用 0–1 数值。

ŷ = β₀ + β₁x
β₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²
β₀ = ȳ − β₁x̄

缺失、常量与解释

每项指标只使用成功率和指标同时有效的实验，n 因而可能不同。少于 2 个样本或任一变量为常量时，相关系数不定义。小样本结果应谨慎解释；相关性不代表因果关系。

Mean ratio / Gain 按源表中的行级公式计算，不等同于逐样本比值或增益的平均。原表缺少的指标保持缺失。
